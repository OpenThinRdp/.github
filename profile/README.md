<p align="center"><b>Free tools for Windows Remote Desktop: reuse the computers you have, and know what is broken before your users call.</b></p>

| | |
|---|---|
| **[OpenThinRDP](https://github.com/OpenThinRdp/openthinrdp)** | The free thin client OS for Windows Remote Desktop. Turns a PC, an old laptop or a used thin client (Dell Wyse, HP, Fujitsu Futro) into a locked-down terminal that opens your Windows desktop: one PC at home, or a whole office on a domain with RDS, VDI and RD Connection Brokers. RDP over UDP, USB and webcams, signed updates with a way back. Open source (GPLv3), no licence per device. **[Download the ISO](https://github.com/OpenThinRdp/openthinrdp/releases/latest)** |
| **[OpenThinRDP Manager](https://github.com/OpenThinRdp/openthinrdp-manager)** | A free health center for the servers behind the desktops: Hyper-V and failover clusters, Proxmox, vSphere, Remote Desktop, Citrix, Active Directory, SQL Server, Veeam, Dell iDRAC and certificates, in one window with no agent. It also manages a fleet of OpenThinRDP thin clients. **[Download](https://github.com/OpenThinRdp/openthinrdp-manager/releases/latest)** |
